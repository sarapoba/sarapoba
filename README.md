# 🚀 루틴 레벨업 캘린더

> **할 일을 완료하면 경험치를 얻고 레벨업하는 게임형 루틴 관리 서비스**

---

## 📌 프로젝트 소개

루틴 레벨업 캘린더는 사용자가 일상 속 할 일을 꾸준히 실천할 수 있도록
**게임 요소(레벨, 경험치, 보상)**를 결합한 일정·습관 관리 서비스입니다.

단순한 체크리스트를 넘어,
**"성장하고 있다는 느낌"**을 제공하는 것이 목표입니다.

---

## ✨ 주요 기능

### ✅ 할 일 & 루틴 관리

* 할 일(Task) 생성 / 수정 / 삭제
* 날짜별 일정 관리
* 반복 루틴 설정 (매일 / 매주)

### ⬆️ 레벨업 시스템

* 할 일 완료 시 경험치 획득
* 경험치 누적에 따른 레벨 상승
* 연속 달성(스트릭) 보너스 제공

### 📊 통계 & 기록

* 일간 / 주간 / 월간 달성률 확인
* 레벨 성장 히스토리
* 완료 기록 시각화

### 🔔 알림 기능

* 할 일 알림
* 루틴 미완료 알림
* 레벨업 알림
